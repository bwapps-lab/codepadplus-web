Autosave

Tags & pinned notes

Line numbers

Find & replace

PLAIN TEXT FIRST

Useful for notes and code snippets.

CodePad+ is intentionally not a full IDE. It focuses on fast, reliable plain-text editing for notes, snippets, configuration files, and source code.
