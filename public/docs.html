CodePad+ User Guide

A short guide to the main features.

Create and edit notes

Tap the floating + button on the Home screen. Start typing immediately. CodePad+ autosaves your note, so there is no normal Save button.

Rename a note

Tap the note title in the editor, or open the overflow menu and choose Rename.

Tags and pinned notes

Use Tags to organize notes. Pin important notes to keep them above the rest of your library. Tags can be renamed or deleted without deleting the notes that use them.

Find and replace

Use the search icon in the editor to find text. You can move between results, replace one result, or replace all matches.

Open files from Android

From your file manager, choose Open with CodePad+ for supported plain-text and code files. The file is imported as a new internal note so the original file is not edited in place.

Save As

Use Save As to export the current note. If you do not provide an extension, CodePad+ uses .txt. Existing extensions such as .json, .md, .xml, or .kt are kept.

Backup and restore

Settings → Data → Backup All creates a JSON backup of your notes and metadata. Restore Backup can merge a backup with existing notes or replace the current library.

Export All

Export All creates a ZIP archive containing your notes as individual files. Notes without a file extension are exported as .txt files.

Editor settings

Settings includes line numbers, coding shortcut bar, word wrap, font family, font size, and theme controls.
